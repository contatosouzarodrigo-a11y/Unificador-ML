Unificador de Etiquetas ML

Junta automaticamente a etiqueta de envio + DANFE na mesma etiqueta, deixando o arquivo pronto para impressão.

Economize 50% de etiquetas: use 1 etiqueta no lugar de 2.
Baixar grátis para Windows
Instale uma vez e deixe o programa trabalhar sozinho.

Como funciona

  1. Instale o programa.
  2. Baixe as etiquetas normalmente no Mercado Livre.
  3. Em cerca de 2 segundos, o PDF pronto abre automaticamente.

Depois de instalado, o programa fica em segundo plano. Você não precisa selecionar arquivos nem converter nada manualmente.

Configuração necessária

✓ Tipo de impressora: Impressora térmica
✓ Formato da etiqueta: ZPL (.txt)
✓ Ativar impressão conjunta do DANFE e arquivos de envio

Caminho: Preferências de venda → Configurações de impressão.
