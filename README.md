# Unificador de Etiquetas ML

**Economize 50% de etiquetas na expedição.**

O programa junta automaticamente a **etiqueta de envio + DANFE na mesma etiqueta**, usando **1 etiqueta no lugar de 2**.

## Como funciona

1. Instale o programa.
2. Baixe normalmente as etiquetas no Mercado Livre.
3. Em cerca de **2 segundos**, o PDF pronto abre automaticamente.

## Configuração no Mercado Livre

Em **Preferências de venda → Configurações de impressão**:

- Tipo de impressora: **Impressora térmica**
- Formato da etiqueta: **ZPL (.txt)**
- **Ativar impressão conjunta do DANFE e arquivos de envio**
